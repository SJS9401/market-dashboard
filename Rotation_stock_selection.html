순환매 장세의 종목 선별 — 전략이 다르면 종목도 다르다

스윙 반등 매매 vs 눌림 단타, 2014–2026 전수 백테스트 · 유니버스: 매일 코스피 시총 상위 200 + 코스닥 상위 150 (상폐 포함, 생존편향 없음) · KRX 일별 OHLC + 수익률(분할 조정) 자체 백필
한 줄 결론. 같은 순환매 장세라도 전략의 신호 원천에 따라 최적 종목이 완전히 갈린다. 지수 스윙 저점에서 반등을 사는 매매는 시총 1위 1종목이 정답이고 (종목 선별 = 마이너스 알파), 개별 종목의 깊은 눌림을 사는 단타는 RS(상대강도) 상위 5~10% 정예가 유일한 플러스 알파다. 소르티노(하락 방어형)는 두 전략 모두에서 기각 — 관찰(정찰) 전용이다.

1. 문제 설정과 방법론

순환매 장세에서 트레이더의 실질 질문은 "언제"가 아니라 "무엇을 사느냐"다. 타이밍(지수 스윙 저점~고점)을 고정한 상태에서 종목 그룹별 성과를 전수 비교했다.

  • 유니버스: 매일 그날 기준 코스피 시총 상위 200 + 코스닥 상위 150 (K200·Q150 근사). 상폐 종목 포함 — 생존편향 없음.
  • 사이클 정의: 지수 ZigZag 3.5% 대칭 — 실전 매매 지점 10개로 캘리브레이션 (9/10 재현, 평균 오차 2일). 2014–2026 스윙 저점 85개. 검증 차트: Swing_lows.html
  • 그룹 정의 (3개월/63일): 지수관련주 = 지수 상관 상위 (실전 = 시총 1위) · RS = 하락일 방어 + 상승일 우위 · 소르티노 = 하락일 방어 + 상승일 소외 · 방어주(양방향 β<0.7)는 사전 제외. 정예 = 그룹 내 점수 상위 5/10/20%.
  • 주도주기 분리: 시총 1위(삼성전자)가 스스로 주도주였던 2016–17, 2025–26 반도체 장세는 별도 표기 — 왜곡 원천이므로 결론은 비주도주기(ex) 기준.
  • 체결 가정: 스윙 = 종가 기준. 눌림 단타 = OHLC 정밀 (지정가 터치 체결, 갭은 시가, 당일 손절 우선의 보수 가정).

2-2. 집중이 분산을 이긴다

총 익스포저 150% 고정, 시총 상위 N종목 등분: 1종목 +14.84% > 2종목 +13.77% > 3종목 +10.96% > 5종목 +10.11% (1 vs 3종목 paired t=3.32, 양 시대 동일 방향). 알파 원천이 하나(지수)이므로 분산은 리스크 분산이 아니라 베타 희석이다. 실용 절충 = 시총 1·2위 75%씩 (단일 종목 갭 리스크 반분, 평균 -1.1%p 비용).

2-4. 실행 룰 (검증 완료)

  • 진입: 저점 예측 금지. 저점 확인 후 당일~+1일 진입이 저점 전일 매수보다 우위 (조기 진입은 하루당 -1.3%p + 손절률 급증). 실패 시 본전 청산이 최악 — -7% 손절 후 저점 재확인 재진입이 정답, 재진입은 절반 익스포저 (손절 클러스터: 직전 손절 0회 손절률 30% → 1회 52% → 2회+ 62%).
  • 손절: -7% 단일 (-3~-6% 전부 열위 — 시총 1위 정상 노이즈 경계가 -6~-7% 사이). 주도주기(변동성 확대)만 -10%.
  • 매도 (이원화): 평상시 = 재량 스윙 고점 우선 (+3.5%p 가치), 기계 안전망 = +10% 도달 후 트레일 -5% 조임. 주도주기 = 트레일 -10% (지점 익절 전면 금지 — 이익의 89%가 +7% 이상 구간에서 나옴). 고정 목표가·되돌림 익절은 전 앵커에서 열위.
  • 오버나이트 구조: 반등 1국면(저점→지수 +7%, 평균 19일) 수익의 84%가 오버나이트 — 종가 매수·시가 매도 단타 유효 (선물/ETF 전용, 현물 거래세면 엣지 소멸). 갭하락 -0.5% 이상 발생일은 장중 매수 (승률 66~80%). 지수 +7% 도달 = 단타 종료 시점.

3-3. 읽는 법

  • 티어 단조성: 상위5 > 상위10 > 상위20 > 전체 — 상대강도가 강할수록 눌림의 복원력이 강하다. 눌림 단타는 "강한 놈의 일시적 눌림"을 사는 전략이므로 RS가 곧 알파.
  • 비주도주기에서도 유지 — 주도주 장세의 산물이 아닌 구조적 엣지.
  • 소르티노 전멸 (전 조합 PF 0.94~1.07): 하락 방어형의 눌림은 복원 연료가 없다. 세 전략(스윙·핸드오프·눌림)에서 일관 기각.
  • 시총 1위는 -10%에서만 유효 (PF 1.61) — 삼전의 정상 변동성(-4~-8%)은 신호가 아니다. 야후·KRX 독립 데이터 교차 일치로 검증.
  • 비용 생존: RS5 -8~-10% 기준 순 +0.75~0.85%/회 (현물 왕복 0.25% 차감), 보유 3일.
  • 종가 백테스트 경고: 같은 룰을 종가로만 돌리면 그룹 구조가 정반대로 나온다 (RS 정예 PF~1.0). 터치 체결·장중 손절이 반영돼야 진실이 보인다 — 단타류 검증은 OHLC 필수.

4. 왜 갈리는가 — 신호의 원천

스윙 반등 = 베타 전달 게임

신호가 지수에서 나온다 (시장 전체의 투매·저점). 최적 종목 = 신호를 손실 없이 전달하는 최순수 베타 = 시총 1위. 어떤 종목 선별도 노이즈 삽입이고, 분산은 희석이다. 종목이 아니라 국면(익스포저)과 규율(손절 -7%, 재진입 감산)로 승부한다.

눌림 단타 = 종목 복원력 게임

신호가 종목에서 나온다 (강한 종목의 일시 이탈). 최적 종목 = 복원력이 검증된 RS 상위 정예. 깊을수록 좋고(-8~-10%), 방어형(소르티노)은 복원 연료가 없어 역선택이다. 시총 1위조차 여기선 -10% 한정 보조 수단.

주도주기 예외 (시총 1위 = 주도주인 시대: 2016–17, 2020–21, 2025–26 반도체). 스윙 매매의 tail(+50%대)은 전부 이 시기의 산물이다. 이 시기엔 ① 갈아타기 전면 금지 (재선별 알파가 사라짐 — 갈아타기 = 주도주를 파는 실수) ② 손절 -10% (변동성 확대로 -7%는 노이즈에 털림: 손절률 26→13%) ③ 처음부터 현물 홀드 + 트레일 -10%. 판별은 시총 1위의 지수 대비 초과수익 (+2.6%p vs -0.8%p로 명확히 갈림).
소르티노의 자리. 세 전략 모두에서 매매 대상으로는 기각. 단 하나의 용도 = 정찰: 소르티노 → RS 변신(하락 방어가 상승 주도로 바뀌는 순간)이 주도주 승격 신호다. 추세 확정(D+20) 후 "그 시점 기준" RS 상위 10% 재선별은 +1.7~3.5%p/20일의 다음 포지션 알파 — 단, 이것은 스윙 매도 이후의 이야기다.

6. 한계와 주의

  • 스윙 국면별 표본이 작다 (n=3~14) — 국면 등급은 방향성 참고, 과신 금지. 눌림 단타는 n 수백~수만으로 탄탄.
  • 스윙 손절은 종가 기준 — 갭이 -7%를 넘는 날의 초과 손실 미반영. 고익스포저(200%)일수록 갭 리스크 상존.
  • 눌림 단타의 동시 신호(같은 날 다수 종목) 자본 배분과 호가 슬리피지는 미모델링 (지정가라 제한적).
  • ZigZag 저점은 사후 확정 — 실전 진입 확인은 재량 (촉매·반전 캔들). 기계식 ±3.5% 확인 매매는 왕복 통행세 7%p로 기각 검증 완료.
  • 주도주기 판별의 실시간 오차 — 기계 판별 정확도 66% 수준, 최종 판단은 재량.
