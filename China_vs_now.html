코스피 — 중국 사이클(03-03-17~) vs 현재(22-09-30~)

로그 스케일 · 저점 앵커 = 각자 저점=100, 고점 앵커 = 각자 정점=100·x=0이 정점. MDD·낙폭은 고가→저가(장중) 기준, 상승률은 종가 기준. 하단 = 전고점(고가) 대비 저가 낙폭 곡선.
FFR·10Y·WTI 버튼 = 우축 매크로 오버레이. 점선 중국(03-03~08-12) / 실선 현재(22-09~). 2004~06 그린스펀 코넌드럼: FFR 17회 인상에도 10Y가 +30bp에 그쳐 한계 자본공급자 채널이 닫히지 않았고 주가는 지속됐다. WTI는 2008-07 $145로 사이클 정점과 동행. 우측 드래그 = 기간 확대(x축만), 좌측 드래그·더블클릭 = 전체 복귀, Ctrl+휠 = 줌. 본 차트와 낙폭 차트는 연동.

주도주 — 현대중공업(03-03-25~) vs SK하이닉스(23-01-03~)

저점 앵커 = 각자 저점=100 (현중 03-03-25 / 하이닉스 23-01-03), 고점 앵커 = 현중 1차 정점(07-11-07)=100 vs 하이닉스 자기 정점=100 · 로그 · 수정주가(naver, OHLC). 낙폭·MDD는 고가→저가(장중) 기준. 세로 점선 = 현중 1차 정점(07-11-07, 중국 사이클)·2차 정점(11-04-08, 해양플랜트 사이클)·하이닉스 정점. 역할 매칭: 현중 = 당시 시총 대장주(2007 코스피 3위) ↔ 하이닉스 = 현 대장주(정점 시 코스피 2위). 현중은 2008 -78% 후 2011 前고점 재돌파(2차 사이클) → 2015 -85% 최종 붕괴의 이중 정점 구조. 우측 드래그 = 기간 확대(x축만), 좌측 드래그·더블클릭 = 전체 복귀, Ctrl+휠 = 줌. 본 차트와 낙폭 차트는 연동. BDI·신조선가·DRAM ASP 버튼 = P 지표를 절대값으로 우축에 오버레이 (BDI·신조선가 = 현중 앵커 기준, DRAM ASP = 하이닉스 앵커 기준) — 주가 대비 P가 언제 꺾였는지 대조. (미포 데이터는 shipbuilding_static.json 에 보존)
정점 후 회복 실패 패턴 — BDI 정점(11,793) 대비 회복률 2009 36% → 2010 36% → 2011-03 13%. 두 번 반등했으나 매번 더 낮은 고점. 중국 수요는 살아있었는데 2003~08 호황기 발주분이 인도되며 공급이 밀려온 탓. 계약가(신조선가)는 정점 190 → 2012 126으로 -34%에 그쳐 훨씬 얕게 빠졌다 — 잔고에 잠긴 가격 vs 즉시 무너지는 현물의 차이.
→ AI 대입: 삼성 "2027 부족 심화·2028 지속"(팹 리드타임 3년 반)이 맞더라도, 지금 짓는 팹들이 2029년 이후 도착해 같은 역할을 할 수 있다.

왜 올랐나 (2003~2008)

중국 도시화·고정자산투자철광석·석탄 물동량 폭증 → BDI 8배. 원자재 슈퍼사이클의 운송 병목.
조선 CAPA 부족1990년대 저선가로 증설 중단 → 수주잔고 3년치 누적. 원화 강세로 2005년부터 선가 본격 상승.
선박금융 팽창독일 KG펀드 등 — 선주의 구매력을 금융이 만들어줌. 지금의 엔비디아 백스톱 자리.

왜 무너졌나 (2008~)

리먼 → 선박금융 붕괴수요(중국 FAI)가 아니라 금융 채널이 먼저 끊겼다. 발주 취소 급증 — 수주잔고는 계약서였을 뿐.
호황기 발주분의 지연 인도2003~08 발주 선박이 2009~12에 인도 — 수요 회복에도 공급이 계속 밀려와 BDI 회복 실패 (36%→36%→13%).
이익은 늦게 무너졌다잔고가 실적을 떠받쳐 분기 OPM 정점은 2010-1Q. 시총 정점(2007-10)보다 2년 5개월 뒤. "실적이 좋다"는 주가 바닥의 근거가 아니었다.
