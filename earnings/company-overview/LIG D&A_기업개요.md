## ① 기업 분류

(1) Primary / Secondary 분류

**Primary 분류: 지속성장 (정부 조달 기반 저변동 마진 + 수출 주도 성장 가속)**

→ 12년 OPM range 0.2%~8.1% = **+7.9pp (cutoff ±10pp 미만)** — 정량 룰상 사이클 분류 아님. 방산원가 규정상 "정부로부터 일정수익률을 보장"(DART 2025 사업보고서 II-4-나)받는 구조가 마진 변동폭을 구조적으로 제한

→ 매출 12년 CAGR **+10.8%**, 최근 3년(FY22→FY25) CAGR **+24.7%** — 천궁-II(M-SAM) 중동 3개국 수출(UAE·사우디·이라크, 계약 합계 약 10.65조원)이 성장 엔진

**Secondary 노트: 수주 사이클 (국내 개발→양산 전환 + 대형 수출 계약의 계단식 유입)**

→ 2015 상장 직후 정점(OPM 5.9%) → **2017~2019 저점 3년**(OPM 0.2~1.6%, 수주잔고 3.2~5.6조로 축소, 2017 4Q 영업손실 −645억) → 2020 회복 → **2022~ 수출 사이클**(수주잔고 12.3조 → 2025말 26.3조)

→ 이익은 "수주잔고의 크기·믹스(수출 vs 내수, 양산 vs 개발)"에 의해 결정되는 lagging 구조 — 수주 사이클이 매출·마진을 2~4년 후행 견인

(3) 정량적 분류 근거

→ **정부 고객 집중**: FY25 방위사업청 46.4% + 국방과학연구소 12.0% + 국방기술진흥연구소 3.7% = **정부·공공 62.1%** (DART 2025 사업보고서 "주요 거래처") — 방산원가 보장 구조로 저마진·저변동

→ **수출 비중 상승**: 6.1% (2016) → 18.3% (2022) → 23.6% (2024) → 19.9% (2025) → **27.9% (1H26)** — 수출은 국내 방산원가 규제 밖이라 마진 개선 레버

→ **수주잔고/매출 = 6.1배** (FY25말 26.25조 / FY25 매출 4.31조) — 향후 6년치 매출 가시성 확보, 단 잔고 중 중동 천궁-II 9.89조(2Q26 기준, 이투데이 2026.08.06)

→ **분기 OPM 변동은 크다**(4Q 비용 집중: 4Q17 −14.7%, 4Q25 2.8% / 1Q 강세: 1Q25 12.5%, 1Q26 14.7%) — 연간 마진은 안정, 분기 마진은 개발비·충당금 인식 시점에 좌우

(4) 산업 분류

→ **한국표준산업분류** — 방위산업 (DART "주된 사업은 방위사업", 2009년 계측기 사업 정리 후 방산전업도 100%)

→ **KRX 업종** — 유가증권시장 (2015.10.02 상장)

→ **사업 성격** — 유도무기 체계종합 + C4ISR 전자전 (지상 플랫폼 중심의 한화에어로스페이스·현대로템, 항공기 중심의 KAI와 차별)

→ **워치리스트 섹터** — T2 방산

(5) 분류 결정 논리

(1) **가장 매출 큰 사업부 기준** — PGM 47.2% (FY25) / 58.9% (1H26) → 유도무기 수요(국내 다층 방공 + 중동 방공 수출)가 Primary driver. PGM 비중은 39%(2024)~73%(2017) 범위에서 C4I 양산(TMMR) 사이클과 교대

(2) **이익 비중 sub-rule** — 사업부별 영업이익은 DART 미공시(단일 "방위산업부문" 보고). 증권사 추정 기준 수출 천궁-II 비중이 큰 PGM이 이익 기여 최대로 판단되나 **확인 불가(회사 미공시)** → 매출 비중 기준으로만 판정

(3) **Boundary case 처리** — OPM range 7.9pp는 cutoff 10pp에 근접. 2017~2019 저점은 "수주 공백 + 개발사업 손실" 사이클이었으므로 **Primary 지속성장 + Secondary 수주 사이클** 병기. 2026.10 방사청 2년 입찰참가 제한이 신규 국내 수주 공백을 만들면 2027~2028 사이클 저점 재현 가능성 → 분기 재평가 트리거로 관리

(4) **국내외 피어 비교** — 국내: 한화에어로스페이스(지상장비·K9·레드백 수출, 플랫폼형), 한화시스템(레이더·C4I, LIG와 ISR/C4I 경합), KAI(항공기, LIG는 KF-21 항전 공급사), 현대로템(K2). 글로벌 유도무기: RTX(Raytheon), Lockheed Martin MFC, MBDA, Rafael, Kongsberg. LIG는 **국내 유일 유도무기 체계종합 전문 상장사** → 피어 대비 "방공 미사일" 순수도 높음 (피어 마진 수치 비교는 이번 버전에서 미검증 — 다음 버전 보완)

(6) 적정 밸류에이션 방법

→ **1차 — Forward PER (12MF EPS)**: 지속성장 분류 + 수주잔고 6배로 이익 가시성 높음 → PER 우선. 2026.09.30 기준 trailing PER 52.0배·forward PER 33.6배·PBR 9.08배(StockAnalysis, 지연 데이터) → 이후 주가 −39%(9/30 682,000원 → 11/02 414,000원, Yahoo)로 멀티플 대폭 하향

→ **2차 — 수주잔고 기반 EV/Backlog 또는 잔고 소진 DCF**: 계약부채(선수금) 3.8~3.9조가 부채의 대부분이라 EV 계산 시 순차입금 해석 주의

→ **3차 — PBR**: ROE 17~20%(2023~2025)로 PBR 단독 사용 부적합. 저점 국면(2017~2019, ROE <1%) 재진입 시에만 PBR 밴드 하단 참조

→ **사이클 기업(삼성전자 PBR 사이클)과 대비**: LIG는 마진 변동이 작고 매출 가시성이 잔고로 확보되는 구조 → PBR보다 PER/잔고 멀티플이 적합

(7) 분기 재평가 트리거 (**분류 변경 조건**)
