① 이번 분기 쟁점 5개

# 쟁점 한 줄 정의 언급
1 Azure 가속의 원천 공급이 늦었는데 어떻게 48%가 나왔나, 효율 개선은 지속 가능한가 7/7 + 해외 다수
2 CapEx 이연과 FCF CapEx 미달은 좋은 소식인가, 하반기 재가속 때 FCF는 버티나 7/7
3 OpenAI 집중도와 RPO 정체 매출 10.8%가 OpenAI, RPO는 QoQ 정체 — 성장의 질은 5/7
4 Copilot·M365 수익화의 측정 좌석 수 미공시·사업부 재편 — 숫자로 검증하기 어려워졌다 5/7
5 마진 지속성과 소비자 부문 OPM 49.8%는 지속되나, Windows -22%는 바닥인가 4/7

② 쟁점별 분해

쟁점 1. Azure 가속의 원천 — "공급 없이 어떻게 48%인가"

(1) 회사 설명 → "수요는 여전히 공급을 초과". GPU 플릿 효율 개선으로 남은 용량을 Foundry에 추가 배분, CPU 플릿에서는 엔지니어링으로 저활용 용량을 찾아 수익화, 토큰당 매출이 예상보다 높음. GB300 가동 소요 기간 20% 단축, 신규 DC 24곳 추가 (신한·하나·삼성) → FQ2 49~50%는 "추가 효율 개선이 필요", 외부 컴퓨팅 용량 인도는 FY27 하반기로 지연 → 분기 변동성 가능 (하나·삼성) → Foundry 고객 12만+(전분기 10만), 매출 3배 이상, 오픈소스 모델 매출 10배 (삼성·신한)

(2) 증권사별 해석

증권사 핵심 가정·추정 논리
키움 같은 설비로 더 많은 사용량 × 더 높은 단가 증설 지연을 효율로 보완. FQ2 QoQ 증분은 $2.8~3.0B로 이번($3.75B)보다 작지만 하반기 외부 용량 유입 시 재확대
SK 효율화를 일회성이 아니라 가이던스에 반영할 만큼 지속 가능한 것으로 회사가 인식 GPU 공급 일부 지연에도 효율화만으로 눈높이를 넘었다. Astra(9월 출시) 효과로 토큰당 매출 상승은 FQ2에 더 기여
신한 Azure 성장률 39.7 → 39.2 → 40.3 → 42.0 → 48.2% → 49%+ 신사업이 아니라 기존 자산의 생산성 개선에서 나왔다는 점에 주목
하나 가이던스 상단 대비 +3%p, FQ2 컨센 대비 +3.5%p 신규 설비 가동 시점·규모에 따라 분기 변동성 예상
삼성 Foundry 성장과 CPU 수익화가 주동력 서드파티 용량 지연으로 분기 변동성 가능
UBS (웹) TP → $700 Azure 48%·50% 성장률이 근거

(3) 공통 결론 vs 갈리는 지점 → 공통: 이번 가속은 증설이 아닌 효율(처리량)과 단가에서 나왔고, 수요 > 공급 구조는 그대로 → 갈림: 효율 개선이 몇 분기나 이어질 수 있는지. SK·키움은 "구조적 효율"로, 하나·삼성은 분기 변동성을 경계

(4) [판단] → 증설 없이 만든 6%p 가속이라 질이 좋다. 하반기에 지연된 외부 용량이 들어오면 "효율 + 증설"이 겹치는 구간이 열린다 — 성장 델타 측면에서 가장 강한 신호 → 다만 회사가 "49~50%에는 추가 효율 개선이 필요"라고 직접 말했다. FQ2에서 48% 이하로 나오면 "효율 1회성" 해석으로 바뀐다

쟁점 2. CapEx 이연과 FCF — "미달은 좋은 소식인가"

(1) 회사 설명 → FQ1 CapEx $45.2B(리스 포함, +30% YoY)로 가이던스 $50B+ 미달 — 외부 컴퓨팅 용량 인도 지연. 약 75%가 CPU·GPU 등 단기 자산(전분기 66%), 메모리·스토리지 단가 상승분 포함. 금융리스 약 $7.4B (신한·삼성) → FQ2 $50B+, CY26 약 $170B(종전 $175B), FY27 하반기 재가속. FY27 FCF 흑자 유지. "매력적인 조건이면 추가 자금원 활용 — 리스는 이미 쓰고 있고, 채권은 신용등급상 접근 가능하나 아직 미사용" (신한·하나)

(2) 증권사별 해석
