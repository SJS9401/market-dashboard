## 2. 지난 분기 체크 결과

Azure 41%+ 재가속(→ 48.2%)과 Cloud GPM 65%+(→ 66%)는 **확인(초과)**. Copilot 좌석은 FQ4 26에 30M+를 공시한 뒤 이번 분기 **공시 중단**. CapEx CY26 $190B 페이스는 **반대로**($170B로 하향), 소비자 부문 바닥 통과도 **반대로**(Windows OEM·기기 -22%). 영업비용 레버리지는 +6.2% YoY로 부분 확인.

## 3. 핵심 쟁점 요약

**(1) Azure 가속의 원천** — 증설이 아니라 효율·단가. SK·키움은 구조적 효율로, 하나·삼성은 분기 변동성을 경계. 회사도 "49~50%엔 추가 효율 개선 필요"라고 언급.

**(2) CapEx 이연과 FCF** — 빅테크 중 유일하게 현금으로 CapEx 감당. 단 이번 흑자엔 투자 이연 효과가 섞여 있고, 신한은 FQ2 FCF -$0.6B를 추정. 첫 외부 조달(채권) 언급.

**(3) OpenAI 집중도·RPO 정체** — OpenAI 매출 $10B(10.8%), RPO $677B로 QoQ 정체(시장 예상 $705.6B 하회). 증가분은 12개월 이후 인식분(+98%)에 몰림.

**(4) Copilot·M365 수익화 측정** — 좌석 수 미공시·사업부 재편으로 검증이 어려워짐. M365 클라우드 17%대 정체, 지표는 좌석 → 사용량으로 전환 중.

**(5) 마진·소비자 부문** — OPM 49.8%는 FQ1 계절 고점, FQ2 가이던스 46.8%. Windows OEM·기기 -22%로 바닥 신호 없음(비중 17%라 전사 영향은 제한).

## 4. 4Q26(FQ2 27) 봐야 할 것

**(1) Azure cc 49~50% 실현 — 1순위**
QoQ 증분 약 $2.9B, 매출 약 $36.1B. 48% 이하면 "효율 일회성"으로 해석이 바뀌며 가속 내러티브 종료. 50% 이상이면 하반기 외부 용량 유입과 겹쳐 "효율 + 증설" 동시 구간 진입.
*모니터링: Ignite(11월) Foundry·Copilot 발표, AWS·GCP 4Q 클라우드 성장률, FQ2 27 실적(2027년 1월 말) / 뉴스 키워드 "Azure growth 50%", "Microsoft Foundry", "Microsoft third-party capacity"*

**(2) FQ2 FCF와 첫 외부 자금 조달**
CapEx $50B+ 구간에서 분기 FCF 0 이상 유지 여부. 회사채 발행과 분기 FCF 적자가 동시에 나오면 "현금으로 감당" 차별점 소멸. FY27 연간 FCF 흑자 가이던스 유지가 마지노선.
*모니터링: SEC 8-K·424B(채권 발행), FQ2 현금흐름표·금융리스 규모 / 뉴스 키워드 "Microsoft bond offering", "Microsoft debt AI"*

**(3) M365 상업 클라우드 cc 약 19% → FY27 중 가속 시작**
17~18%에 머무는 한 Copilot은 아직 델타 엔진이 아님. 사용량 과금 고객(+75% QoQ)·DAU 지표가 매출로 연결되는지.
*모니터링: FQ2 M365 클라우드 성장률, E7·Copilot 사용량 코멘트 / 뉴스 키워드 "M365 Copilot usage", "Microsoft E7"*

**(4) RPO $680B 정체 탈피 + OpenAI 매출 비중**
신규 기업 계약으로 $700B+ 재증가하면 집중도 우려 완화. OpenAI 비중 11% 상회 지속 시 성장의 질 논쟁 확대.
*모니터링: FQ2 상업 RPO·cRPO, OpenAI·Anthropic 계약 뉴스 / 뉴스 키워드 "OpenAI Microsoft revenue share", "Microsoft RPO", "Anthropic Azure"*

**(5) OPM 46.8% 가이던스 대비 위치 + Cloud GPM 65%**
단기 자산(CPU·GPU) 비중 75%로 감가상각이 빠르게 늘어나는 구간의 마진 방어. 메모리 단가 상승이 CapEx·D&C 양쪽에 부담.
*모니터링: FQ2 실적, DRAM 계약가 / 뉴스 키워드 "Microsoft cloud gross margin", "DRAM contract price"*
